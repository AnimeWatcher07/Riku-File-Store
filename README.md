✨ About

Riku Link Changer is an advanced Telegram bot built to make channel link management easier, faster, and more secure.

It provides a centralized admin panel where channel owners can manage invite links, configure force subscription, automate join requests, broadcast messages, and monitor bot activity.

🚀 Features

- 🔗 Temporary Channel Invite Links
- 🔐 Protected Link Generation
- 📢 Force Subscription System
- ✅ Automatic Join Request Approval
- 📦 Bulk Link Generation
- 🌐 Custom URL Generation
- 📣 Broadcast Messages
- 📊 Live Statistics & Analytics
- 👑 Multiple Admin Support
- 🚫 User Ban & Unban
- 🏷️ Custom Bot Branding
- 💾 Automatic Database Backup
- ☁️ MongoDB Cloud Storage Support
- ❤️ Bot Health Monitoring
- 🔄 Automatic Link Expiration
- 🗑️ Automatic Message Deletion

🎛️ Admin Panel

The bot includes a button-based administration panel.

Available sections:

Section| Function

Auto Approve| Manage join requests
Broadcast| Send messages to users

Admins| Manage administrators

Backup| Manage database backups

🔗 How It Works

1. Start the bot using "/start".
2. Open the Admin Panel.
3. Add your Telegram channel.
4. Make the bot an administrator in that channel.
5. Generate a protected bot link.
6. Share the generated link with users.
7. Users receive an invite link according to your settings.

📥 Installation

Clone your GitHub repository:

git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git

Open the project directory:

cd YOUR_REPOSITORY

Install dependencies:

pip install -r requirements.txt

Configure the required environment variables:

TG_BOT_TOKEN=YOUR_BOT_TOKEN
OWNER_ID=YOUR_TELEGRAM_ID

Start the bot:

python main.py

🔒 Security

- Keep your Telegram bot token private.
- Never publish database credentials.
- Never upload private environment variables.
- Give the bot only the permissions it needs.
- Keep your database backup secure.
