## 💎 ABOUT THE PROJECT

**Riku Link Changer** is an advanced Telegram automation bot designed to make channel link management simple, efficient and reliable.

Manage channels, generate protected invite links, automate join requests and control everything through a beautiful button-based admin panel.

## 🚀 FEATURES

| Feature | Description |
|:---|:---|
| 🔗 Link Generator | Generate channel invite links |
| 🔐 Secure Links | Protected link management |
| 📢 Force Subscribe | Require users to join channels |
| ✅ Auto Approve | Automatically handle join requests |
| 📦 Bulk Generation | Generate multiple links |
| 📊 Statistics | Track users and clicks |
| 👑 Admin Panel | Manage bot settings |
| 📣 Broadcast | Send messages to users |
| 🚫 Ban System | Manage blocked users |
| 💾 Backup System | Backup and restore database |
| ☁️ MongoDB Support | Optional cloud synchronization |
| ⏳ Auto Expiry | Automatically expire invite links |

## ⚙️ TECHNOLOGY STACK

- **Language:** Python 3.11
- **Platform:** Telegram Bot API
- **Database:** SQLite
- **Cloud Database:** MongoDB (Optional)
- **Architecture:** Asynchronous Python

## 📥 INSTALLATION

### 1. Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

### 2. Open Project

```bash
cd YOUR_REPOSITORY
```

### 3. Install Requirements

```bash
pip install -r requirements.txt
```

### 4. Configure Environment Variables

Set your required bot credentials and configuration in your hosting environment.

### 5. Start Bot

```bash
python main.py
```

## 🌐 DEPLOYMENT

Recommended deployment configuration:

| Configuration | Value |
|:---|:---|

## 🔒 SECURITY

- Never share your bot token.
- Keep database credentials private.
- Use secure environment variables.
- Restrict admin access to trusted users.
- Maintain regular database backups.
